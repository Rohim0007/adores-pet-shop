# ADORE'S PET E-Commerce Platform

A modular web-based e-commerce platform designed for pet breeding and supplies management (Rabbits, Hamsters, Pet Food & Accessories).

## File Structure
- **index.html**: Customer storefront.
- **admin.html**: Admin control panel.
- **shop.js / cart.js / orders.js**: Core customer logic.
- **admin.js**: Admin operations and inventory management.
- **storage.js / utils.js / config.js**: Helper and configuration modules.
